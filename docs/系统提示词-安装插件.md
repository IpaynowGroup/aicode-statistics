# 安装 aicode-stats 插件系统提示词

## 步骤 1: 安装工具

执行命令：
```bash
npm install -g ipaynow-aicode-stats
```

验证安装：
```bash
aicode --version
```

**成功标志**：显示命令使用帮助信息

---

## 步骤 2: 初始化 MySQL 连接

执行命令：
```bash
aicode config mysql
```

交互式配置以下信息：
- **MySQL 主机地址**：如 `192.168.129.248`
- **端口**：默认 `3306`
- **数据库名**：如 `aicoding`
- **用户名**：如 `aicode_user`
- **密码**：输入数据库密码

验证配置：
```bash
aicode status
```

**成功标志**：显示 MySQL 连接信息（主机、端口、数据库、用户）

---
