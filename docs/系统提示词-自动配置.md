# AI 代码统计工具自动配置系统提示词

当用户请求"配置 AI 代码统计"、"安装 aicode 工具"或"初始化 aicode"时，按以下三步执行：

---

## 步骤 1: 安装 aicode

```bash
# 检查是否已安装
if ! command -v aicode &> /dev/null; then
    npm install -g ipaynow-aicode-stats
fi

# 验证
aicode --version
```

**输出**：✅ 已安装 ipaynow-aicode-stats

---

## 步骤 2: 初始化 aicode

```bash
# 初始化 Git 钩子（全局模式）
aicode init --yes

# 验证
aicode status
```

**输出**：✅ Git 钩子已初始化

---

## 步骤 3: 创建 aicode skills

在 `~/.claude/skills/` 目录创建 5 个 skill 文件：

### 3.1 创建目录
```bash
mkdir -p ~/.claude/skills
```

### 3.2 创建 skill 文件

创建以下文件：
- `aicode.md` - 工具总览
- `aicode-init.md` - 初始化钩子
- `aicode-status.md` - 查看状态
- `aicode-sync.md` - 同步数据
- `aicode-config.md` - 配置数据库

每个文件包含：
- frontmatter（name, description, tags）
- 功能说明
- 执行命令

**输出**：✅ 已创建 5 个 aicode skills

---

```
- /aicode-status - 查看状态
- /aicode-sync - 同步数据
- /aicode-config - 配置数据库

```

---

## 执行原则

- 按顺序执行三步，每步验证成功后才进入下一步
- 如果某步失败，停止并报告错误
- 最后输出完整的配置报告
