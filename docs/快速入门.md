# aicode 快速入门（5 分钟）

> 适用于使用 Codex 和 Claude Code 的开发者

---

## 📦 1. 安装工具（2 分钟）

```bash
# 从本地仓库安装
cd /path/to/aicode-repo
npm run build
npm install -g .

# 验证
aicode --version
```

---

## ⚙️ 2. 配置 MySQL（2 分钟）

### 方式 A：交互式配置（推荐）

```bash
aicode config mysql
```

按提示输入团队提供的连接信息：
- Host: `db.example.com`
- Port: `3306` （回车使用默认）
- Database: `ai_stats`
- User: `aicode_writer`
- Password: `****` （输入不显示）

### 方式 B：环境变量（更安全）

在 `~/.zshrc` 或 `~/.bashrc` 添加：

```bash
export AICODE_MYSQL_PASSWORD="团队提供的密码"
```

然后执行：
```bash
source ~/.zshrc  # 或 ~/.bashrc
aicode config mysql  # 会自动使用环境变量中的密码
```

---

## 🔧 3. 安装钩子（1 分钟）

```bash
# 全局模式（统计本机所有仓库）
aicode init
# 看到改动列表后输入 y 确认
```

---

## ✅ 4. 验证安装

```bash
aicode status
```

期望看到：
```
上报目标：MySQL (db.example.com:3306/ai_stats)
本地积压：0 条事件
最近成功时间：...
```

## 🎯 完成！

现在每次用 Codex/Claude Code 修改代码并 `git commit` 后，统计数据会自动上报到团队数据库。

### 常用命令

```bash
aicode status  # 查看状态
aicode sync    # 手动同步积压数据
```

### 遇到问题？

查看完整手册：`docs/团队安装配置手册.md`

或查看日志：
```bash
cat ~/.aicode/logs/aicode.log
```

---

## ⚠️ 常见错误

### 错误 1：同步失败

```bash
# 检查配置
aicode status

# 重新配置
aicode config mysql

# 重试同步
aicode sync
```

### 错误 2：提交后没有统计

```bash
# 查看本地积压
aicode status

# 如果有积压，手动同步
aicode sync

# 查看日志
tail -20 ~/.aicode/logs/aicode.log
```

### 错误 3：GUI git 客户端提交没统计

**原因**：GUI 读不到环境变量

**解决**：把密码写入配置文件
```bash
nano ~/.aicode/config.json
# 在 reporter.options 中添加：
#   "password": "实际密码"

chmod 600 ~/.aicode/config.json
```
