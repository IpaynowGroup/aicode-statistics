# AI 代码统计工具完整安装配置指南

本文档提供 `ipaynow-aicode-stats` 工具的完整安装、配置和使用说明，包括在 Claude Code 和 GitHub Copilot 中的集成。

---

## 📦 1. 安装工具

### 1.1 全局安装

```bash
npm install -g ipaynow-aicode-stats
```

### 1.2 验证安装

```bash
aicode --version
```

应显示命令帮助信息。

---

## 🔧 2. 初始化 Git 钩子

### 2.1 全局模式（推荐）

适用于所有 Git 仓库：

```bash
aicode init --yes
```

这会在全局 Git 配置中安装钩子，影响所有新克隆和现有的仓库。

### 2.2 本地模式

仅对当前仓库生效：

```bash
cd /path/to/your/repo
aicode init --local --yes
```

### 2.3 验证钩子安装

```bash
# 检查全局钩子目录
git config --global core.hooksPath

# 或检查本地钩子
ls -la .git/hooks/ | grep -E "(pre-commit|post-commit)"
```

## 🗄️ 3. 配置 MySQL 数据库

### 3.1 准备数据库

```bash
# 1. 创建数据库
mysql -h host -u root -p -e "CREATE DATABASE aicoding CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2. 创建用户并授权
mysql -h host -u root -p -e "
CREATE USER 'aicode_user'@'%' IDENTIFIED BY 'your_password';
GRANT SELECT, INSERT, UPDATE ON aicoding.* TO 'aicode_user'@'%';
FLUSH PRIVILEGES;
"

# 3. 导入表结构
cat node_modules/ipaynow-aicode-stats/sql/schema.sql
mysql -h host -u aicode_user -p aicoding < node_modules/ipaynow-aicode-stats/sql/schema.sql
```

### 3.2 配置工具连接

```bash
aicode config mysql
```

交互式输入：
- **主机地址**：如 `192.168.129.248`
- **端口**：默认 `3306`
- **数据库名**：如 `aicoding`
- **用户名**：如 `aicode_user`
- **密码**：你设置的密码

配置会保存到 `~/.aicode/config.json`（权限 600）

### 3.3 验证配置

```bash
aicode status
```

应显示 MySQL 连接信息和统计状态。

## 🎯 4. 仓库追踪配置

### 4.1 统计所有仓库（默认）

```bash
aicode track --all
```

### 4.2 仅统计特定仓库

```bash
# 在需要统计的仓库中执行
cd /path/to/important/repo
aicode track

# 查看追踪列表
aicode track --list
```

### 4.3 排除某个仓库

```bash
cd /path/to/repo
aicode untrack
```

## 🤖 5. Claude Code 集成

### 5.1 安装 Claude Code Skills

将本项目的 skills 复制到全局 Claude 配置目录：

```bash
# 方法 1：复制到全局 skills 目录
mkdir -p ~/.claude/skills
cp -r .claude/skills/* ~/.claude/skills/

# 方法 2：在项目中使用（项目级 skills）
# skills 已在项目的 .claude/skills/ 目录中
```

### 5.2 可用的 Skills

安装后，在 Claude Code 中可以使用：

| Skill 命令 | 功能 | 使用场景 |
|-----------|------|---------|
| `/aicode` | 查看工具使用指南 | 快速了解所有功能 |
| `/aicode-init` | 初始化 Git 钩子 | 新仓库首次配置 |
| `/aicode-status` | 查看统计状态 | 检查运行状态和积压 |
| `/aicode-sync` | 同步统计数据 | 手动上报积压事件 |
| `/aicode-config` | 配置 MySQL 连接 | 首次配置或更改数据库 |

### 5.3 使用示例

在 Claude Code 对话中：

```
你：/aicode-status
Claude：📊 AI 代码统计状态
        统计模式：所有仓库
        数据库配置：✅ MySQL 192.168.129.248:3306/aicoding
        同步状态：✅ 本地积压 0 条

你：帮我同步一下统计数据
Claude：[执行 aicode sync 并报告结果]
```

### 5.4 自然语言调用

也可以直接说：
- "查看 aicode 状态"
- "同步 aicode 数据"
- "初始化 aicode 统计钩子"

Claude Code 会自动识别并调用相应的 skill。

## 💻 6. GitHub Codex 集成

### 6.1 Codex 钩子自动触发

当使用 GitHub Copilot 时，工具会自动检测并记录：

```bash
# 在提交时，pre-commit 钩子会检测 Copilot 使用
git commit -m "feat: add new feature"

# 如果检测到 Copilot，会记录到统计数据
```

### 6.2 手动触发统计

```bash
# 模拟 Codex 钩子调用
aicode hook pre --tool codex
aicode hook post --tool codex
```

### 6.3 验证 Codex 统计

提交后检查数据库：

```sql
SELECT * FROM ai_code_commits 
WHERE tool = 'codex' 
ORDER BY created_at DESC 
LIMIT 10;
```

## 📊 7. 日常使用

### 7.1 正常工作流

```bash
# 1. 正常编码（使用 Claude Code 或 Copilot）
# 2. 正常提交
git add .
git commit -m "feat: implement new feature"

# 钩子会自动：
# - 检测 AI 工具使用（Claude/Codex）
# - 统计代码行数
# - 记录到本地队列
# - 后台上报到 MySQL
```

### 7.2 定期检查

```bash
# 查看统计状态
aicode status

# 如果有积压，手动同步
aicode sync
```

### 7.3 在 CI/CD 中使用

在 `.github/workflows/aicode-sync.yml` 中：

```yaml
name: Sync AI Code Stats

on:
  schedule:
    - cron: '0 */6 * * *'  # 每 6 小时

jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - name: Install aicode
        run: npm install -g ipaynow-aicode-stats
      
      - name: Sync stats
        env:
          AICODE_MYSQL_PASSWORD: ${{ secrets.AICODE_MYSQL_PASSWORD }}
        run: |
          aicode config mysql --host $DB_HOST --port 3306 \
            --database aicoding --user aicode_user --password $AICODE_MYSQL_PASSWORD
          aicode status
          aicode sync
```

## 🔍 8. 数据查询

### 8.1 查询提交统计

```sql
-- 按工具统计
SELECT tool, COUNT(*) as commits, SUM(lines_added) as total_lines
FROM ai_code_commits
GROUP BY tool;

-- 按日期统计
SELECT DATE(created_at) as date, COUNT(*) as commits
FROM ai_code_commits
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)
GROUP BY DATE(created_at)
ORDER BY date;

-- 按用户统计
SELECT author, tool, COUNT(*) as commits
FROM ai_code_commits
GROUP BY author, tool
ORDER BY commits DESC;
```

### 8.2 查询仓库统计

```sql
-- 最活跃的仓库
SELECT repo_name, COUNT(*) as commits
FROM ai_code_commits
GROUP BY repo_name
ORDER BY commits DESC
LIMIT 10;
```

## 🛠️ 9. 故障排查

### 9.1 钩子未触发

**症状**：提交后没有统计数据

**检查**：
```bash
# 检查钩子是否安装
ls -la .git/hooks/

# 检查钩子权限
chmod +x .git/hooks/pre-commit
chmod +x .git/hooks/post-commit

# 手动测试钩子
.git/hooks/pre-commit
```

### 9.2 数据未上报

**症状**：本地积压事件一直增加

**检查**：
```bash
# 查看状态
aicode status

# 检查 MySQL 连接
mysql -h host -u user -p -e "SELECT 1;"

# 手动同步
aicode sync

# 查看错误日志
cat ~/.aicode/sync.log
```

### 9.3 Skills 无法使用

**症状**：在 Claude Code 中找不到 `/aicode-*` 命令

**解决**：
```bash
# 检查 skills 目录
ls -la ~/.claude/skills/

# 重新复制 skills
cp -r .claude/skills/* ~/.claude/skills/

# 重启 Claude Code
```

### 9.4 MySQL 连接失败

**检查清单**：
- [ ] MySQL 服务是否运行
- [ ] 网络是否可达（ping/telnet）
- [ ] 用户名密码是否正确
- [ ] 数据库是否存在
- [ ] 用户是否有权限
- [ ] 防火墙规则

```bash
# 测试连接
telnet db_host 3306
mysql -h db_host -u user -p -e "SHOW DATABASES;"

# 检查权限
mysql -h db_host -u user -p -e "SHOW GRANTS;"
```

## 📚 10. 团队部署建议

### 10.1 统一配置

创建团队配置脚本 `setup-aicode.sh`：

```bash
#!/bin/bash

echo "=== AI 代码统计工具配置 ==="

# 1. 安装工具
npm install -g ipaynow-aicode-stats

# 2. 初始化钩子
aicode init --yes

# 3. 配置 MySQL（使用环境变量）
export AICODE_MYSQL_HOST="${AICODE_MYSQL_HOST:-192.168.129.248}"
export AICODE_MYSQL_PORT="${AICODE_MYSQL_PORT:-3306}"
export AICODE_MYSQL_DATABASE="${AICODE_MYSQL_DATABASE:-aicoding}"
export AICODE_MYSQL_USER="${AICODE_MYSQL_USER:-aicode_user}"

# 交互式输入密码
aicode config mysql

# 4. 验证
aicode status

echo "=== 配置完成 ==="
```
