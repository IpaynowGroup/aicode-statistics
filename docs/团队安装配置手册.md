## 1. 前置准备

### 环境要求

| 软件 | 版本要求 |
|------|----------|
| Node.js | ≥ 18 |
| git | ≥ 2.15 |
| MySQL | ≥ 5.6 |
| Codex CLI | 任意版本 |
| Claude Code | 任意版本 |

### 需要的信息

从团队管理员处获取以下信息：
- MySQL 数据库地址（host）
- 端口（port，一般是 3306）
- 数据库名（database）
- 用户名（user）
- 密码（password）

## 2. 开发者安装步骤

### 2.1 安装 aicode 工具

```bash
# 方式 1：从 npm 全局安装（推荐，等工具发布后）
npm install -g aicode-stats

# 方式 2：从本地仓库安装（当前方式）
cd /path/to/aicode-repo
npm run build
npm install -g .
```

验证安装：
```bash
aicode --version
```

### 2.2 配置 MySQL 连接

**方式 A：交互式配置向导（推荐）**

```bash
aicode config mysql
```

按提示依次输入：
- MySQL 服务器地址：`db.example.com`
- 端口：`3306`（默认，直接回车）
- 数据库名：`ai_stats`
- 用户名：`aicode_writer`
- 密码：`<输入团队提供的密码>` **（输入时不显示）**

配置完成后会自动测试连接和权限。

**方式 B：手动编辑配置文件**

编辑 `~/.aicode/config.json`：

```json
{
  "owner": {
    "name": "你的姓名",
    "email": "your.email@company.com"
  },
  "reporter": {
    "type": "mysql",
    "options": {
      "host": "db.example.com",
      "port": 3306,
      "database": "ai_stats",
      "user": "aicode_writer",
      "password": "团队提供的密码"
    }
  }
}
```

保存后，验证文件权限：
```bash
chmod 600 ~/.aicode/config.json
```

**方式 C：使用环境变量（推荐用于密码）**

在 `~/.bashrc` 或 `~/.zshrc` 中添加：

```bash
export AICODE_MYSQL_PASSWORD="团队提供的密码"
```

然后配置文件中可以省略 password：

```json
{
  "reporter": {
    "type": "mysql",
    "options": {
      "host": "db.example.com",
      "port": 3306,
      "database": "ai_stats",
      "user": "aicode_writer"
    }
  }
}
```

### 2.3 安装钩子（全局模式 - 推荐）

全局模式会统计本机所有 git 仓库的 AI 代码：

```bash
aicode init
```

**会改动的文件**（会先备份）：
- `~/.claude/settings.json` - 添加 Claude Code 钩子
- `~/.codex/config.toml` - 添加 Codex 钩子
- `~/.aicode/git-hooks/` - 创建 git 全局钩子目录
- Git 全局配置 `core.hooksPath`

确认改动后输入 `y` 继续。

### 2.4 可选：项目模式安装

如果只想统计特定仓库：

```bash
cd /path/to/your-project
aicode init --local
```

**会改动的文件**（会先备份）：
- `.claude/settings.local.json`
- `.codex/config.toml`
- `.git/hooks/post-commit`

## 4. 常见问题

### Q1: 配置向导提示"请在交互终端中运行"

**原因**：`aicode config mysql` 需要交互式输入密码。

**解决方案**：
- 在真实终端中运行，不要在 IDE 集成终端或 Agent 中运行
- 或使用方式 B/C 手动配置

### Q2: 同步失败："You have an error in your SQL syntax"

**原因**：早期版本的 SQL 语句有语法错误。

**解决方案**：
```bash
cd /path/to/aicode-repo
git pull  # 拉取最新代码
npm run build
npm install -g .
```

### Q3: 提交后没有统计数据

**排查步骤**：

1. 检查是否安装成功
   ```bash
   aicode status
   ```

2. 查看本地日志
   ```bash
   cat ~/.aicode/logs/aicode.log
   ```

3. 检查 git hook 是否生效
   ```bash
   # 全局模式
   git config --global core.hooksPath
   # 应该输出：/Users/你的用户名/.aicode/git-hooks
   
   # 项目模式
   ls -la .git/hooks/post-commit
   ```

4. 查看本地积压
   ```bash
   aicode status
   # 如果"本地积压"不为 0，说明采集成功但未上报
   aicode sync  # 手动同步
   ```

### Q4: 使用 husky 的项目无法统计

**原因**：husky v5+ 会设置仓库级的 `core.hooksPath`，覆盖全局设置。

**解决方案**：
- 使用项目模式：`cd project && aicode init --local`
- 或在 husky 的 `post-commit` 中手动添加 `aicode commit &`

### Q5: GUI git 客户端提交后没有统计

**原因**：GUI 客户端可能读不到环境变量 `AICODE_MYSQL_PASSWORD`。

**解决方案**：
将密码直接写入 `~/.aicode/config.json`：
```json
{
  "reporter": {
    "type": "mysql",
    "options": {
      "password": "实际密码"
    }
  }
}
```

确保文件权限：
```bash
chmod 600 ~/.aicode/config.json
```

### Q6: Codex 项目没有统计

**排查步骤**：

1. 检查 Codex 钩子配置
   ```bash
   cat ~/.codex/config.toml | grep -A 5 "hooks"
   ```

2. 检查项目信任状态
   ```bash
   # 项目模式需要 Codex 信任该项目
   # 在 Codex 中打开项目时会提示信任
   ```

3. 查看日志
   ```bash
   cat ~/.aicode/logs/aicode.log | grep codex
   ```

## 5. 卸载方法

### 全局卸载

```bash
aicode init --uninstall
```

会移除：
- `~/.claude/settings.json` 中的 aicode 钩子
- `~/.codex/config.toml` 中的 aicode 钩子
- Git 全局 `core.hooksPath` 设置（如果原来有会恢复）

**不会删除**：
- `~/.aicode/` 目录（统计数据保留）
- 全局安装的 `aicode` 命令

### 项目卸载

```bash
cd /path/to/project
aicode init --local --uninstall
```

### 完全清理

```bash
# 卸载钩子
aicode init --uninstall

# 删除数据
rm -rf ~/.aicode

# 卸载命令
npm uninstall -g aicode-stats
```

## 6. 进阶配置

### 6.1 配置模块映射

编辑 `~/.aicode/config.json`：

```json
{
  "modules": [
    { "path": "src/user/**", "name": "user-center" },
    { "path": "src/order/**", "name": "order" },
    { "path": "src/payment/**", "name": "payment" }
  ]
}
```

统计时会按文件路径自动归属到对应模块。

### 6.2 忽略特定文件

```json
{
  "ignore": [
    "docs/generated/**",
    "**/*.test.ts",
    "**/dist/**"
  ]
}
```

### 6.3 只统计特定仓库

```bash
# 把当前仓库加入统计名单（会切换到"仅名单"模式）
cd /path/to/project
aicode track

# 查看名单
aicode track --list

# 移出名单
aicode untrack

# 恢复统计所有仓库
aicode track --all
```

## 8. 数据查询示例

### 查看个人统计

```sql
SELECT 
  owner_name,
  COUNT(*) as commits,
  SUM(added_ai) as ai_lines,
  AVG(ai_ratio) as avg_ratio
FROM ai_commit
WHERE owner_email = 'your.email@company.com'
  AND committed_at >= DATE_SUB(NOW(), INTERVAL 30 DAY);
```

### 查看团队统计

```sql
SELECT 
  owner_name,
  SUM(added_ai) as total_ai_lines,
  AVG(ai_ratio) as avg_ratio,
  AVG(ai_accept_rate) as avg_accept_rate
FROM ai_commit
WHERE committed_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)
GROUP BY owner_name
ORDER BY total_ai_lines DESC;
```

### 按工具统计

```sql
SELECT 
  tool,
  model,
  SUM(ai) as total_ai_lines,
  SUM(`generated`) as total_generated,
  ROUND(SUM(ai) / SUM(`generated`), 3) as accept_rate
FROM ai_commit_tool
GROUP BY tool, model
ORDER BY total_ai_lines DESC;
```
