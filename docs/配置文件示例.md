# aicode 配置文件示例

## 基础配置

### ~/.aicode/config.json（全局配置）

```json
{
  "owner": {
    "name": "张三",
    "email": "zhangsan@example.com"
  },
  "modules": [
    { "path": "src/user/**", "name": "user-center" },
    { "path": "src/order/**", "name": "order" },
    { "path": "src/payment/**", "name": "payment" },
    { "path": "src/common/**", "name": "common" }
  ],
  "ignore": [
    "docs/generated/**",
    "**/*.test.ts",
    "**/*.spec.ts",
    "**/dist/**",
    "**/build/**"
  ],
  "reporter": {
    "type": "mysql",
    "options": {
      "host": "db.example.com",
      "port": 3306,
      "database": "ai_stats",
      "user": "aicode_writer",
      "password": "可选，建议用环境变量"
    }
  },
  "track": {
    "mode": "all",
    "repos": []
  }
}
```

## 配置项说明

### owner（提交者信息）

```json
{
  "owner": {
    "name": "你的姓名",
    "email": "your.email@company.com"
  }
}
```

- **优先级**：配置文件 > git 全局配置
- **用途**：统计时标识代码贡献者
- **建议**：使用真实姓名和公司邮箱

---

### modules（模块映射）

```json
{
  "modules": [
    { "path": "src/user/**", "name": "user-center" },
    { "path": "src/order/**", "name": "order" }
  ]
}
```

- **匹配规则**：从上到下，第一个命中的生效
- **glob 支持**：`**`（任意层级）、`*`（单层）、`?`（单字符）
- **默认值**：未命中时从分支名提取（如 `feature/login` → `login`）
- **用途**：按模块统计代码分布

---

### ignore（忽略文件）

```json
{
  "ignore": [
    "*.lock",
    "package-lock.json",
    "**/*.min.js",
    "**/node_modules/**",
    "docs/generated/**"
  ]
}
```

- **内置规则**：lock 文件、*.min.js、vendor/、生成代码等已自动忽略
- **自定义**：追加项目特定的忽略规则
- **linguist-generated**：`.gitattributes` 中标记的也会忽略

---

### reporter（上报配置）

#### MySQL 直连

```json
{
  "reporter": {
    "type": "mysql",
    "options": {
      "host": "db.example.com",
      "port": 3306,
      "database": "ai_stats",
      "user": "aicode_writer",
      "password": "可选"
    }
  }
}
```

**密码优先级**：
1. 环境变量 `AICODE_MYSQL_PASSWORD`（推荐）
2. 配置文件 `options.password`

#### 自定义 Reporter

```json
{
  "reporter": {
    "type": "module",
    "module": "/absolute/path/to/my-reporter.mjs",
    "options": {
      "url": "https://your-api.com/stats",
      "token": "your-token"
    }
  }
}
```

#### 不上报（仅本地）

```json
{
  "reporter": {
    "type": "noop"
  }
}
```

---

### track（统计名单）

```json
{
  "track": {
    "mode": "all",
    "repos": []
  }
}
```

**mode 选项**：
- `"all"`：统计所有仓库（默认）
- `"list"`：仅统计 `repos` 中的仓库

**repos 格式**：
```json
{
  "repos": [
    "gitlab.example.com/group/project1",
    "gitlab.example.com/group/project2",
    "local:/Users/user/my-project"
  ]
}
```

**管理命令**：
```bash
aicode track          # 加入当前仓库
aicode untrack        # 移出当前仓库
aicode track --list   # 查看名单
aicode track --all    # 恢复统计所有仓库
```

## 项目级配置

### .aicode.json（仓库根目录）

```json
{
  "owner": {
    "name": "项目负责人",
    "email": "owner@example.com"
  },
  "modules": [
    { "path": "frontend/**", "name": "frontend" },
    { "path": "backend/**", "name": "backend" }
  ],
  "ignore": [
    "tests/fixtures/**"
  ]
}
```

**限制**：
- ✅ 可以覆盖：`owner`、`modules`、`ignore`
- ❌ 不能覆盖：`reporter`、`track`（防止恶意代码执行）

---

## 环境变量

### AICODE_MYSQL_PASSWORD

```bash
# ~/.zshrc 或 ~/.bashrc
export AICODE_MYSQL_PASSWORD="your-password"
```

**优势**：
- ✅ 密码不写入配置文件
- ✅ 更安全
- ✅ 易于在不同环境切换

**注意**：
- GUI git 客户端可能读不到，需要写入配置文件
- 环境变量优先级高于配置文件

### 场景 4：自定义 Reporter

```json
{
  "owner": {
    "name": "赵六",
    "email": "zhaoliu@example.com"
  },
  "reporter": {
    "type": "module",
    "module": "/Users/zhaoliu/my-reporter.mjs",
    "options": {
      "url": "https://api.example.com/stats/collect",
      "apiKey": "your-api-key",
      "timeout": 5000
    }
  }
}
```

**my-reporter.mjs**：
```javascript
export default (options) => ({
  name: 'custom-api',
  async report(event) {
    const res = await fetch(options.url, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${options.apiKey}`
      },
      body: JSON.stringify(event)
    });
    if (!res.ok) {
      throw new Error(`HTTP ${res.status}: ${await res.text()}`);
    }
  }
});
```

## 配置验证

### 验证配置语法

```bash
# 查看当前配置
cat ~/.aicode/config.json | jq '.'

# 如果有语法错误，jq 会报错
```

### 验证 MySQL 连接

```bash
# 使用配置向导测试
aicode config mysql  # 会自动测试连接

# 或手动测试
mysql -h <host> -P <port> -u <user> -p<password> <database>
```

### 验证完整流程

```bash
# 1. 查看状态
aicode status

# 2. 手动同步
aicode sync

# 3. 测试提交
cd /path/to/test-repo
echo "test" >> test.txt
git add test.txt
git commit -m "test: 测试 aicode"

# 4. 查看结果
aicode status
```

## 配置文件位置

| 文件 | 路径 | 权限 | 说明 |
|------|------|------|------|
| 全局配置 | `~/.aicode/config.json` | 600 | 必须，aicode init 会创建 |
| 项目配置 | `<repo>/.aicode.json` | 644 | 可选，覆盖部分字段 |
| 同步状态 | `~/.aicode/sync-state.json` | 644 | 自动管理 |
| 安装状态 | `~/.aicode/install-state.json` | 644 | 自动管理 |

---

## 配置优先级

```
环境变量 AICODE_MYSQL_PASSWORD
    ↓
全局配置 ~/.aicode/config.json
    ↓
项目配置 .aicode.json (仅 owner/modules/ignore)
    ↓
git 配置 user.name / user.email (owner 未设置时)
    ↓
分支名推断 (module 未匹配时)
```

## 配置备份与恢复

### 备份

```bash
# 备份配置
cp ~/.aicode/config.json ~/.aicode/config.json.backup

# 备份全部数据
tar -czf aicode-backup-$(date +%Y%m%d).tar.gz ~/.aicode/
```

### 恢复

```bash
# 恢复配置
cp ~/.aicode/config.json.backup ~/.aicode/config.json

# 恢复全部数据
tar -xzf aicode-backup-20261012.tar.gz -C ~/
```

## 配置迁移

### 从旧机器迁移到新机器

```bash
# 旧机器：打包配置和历史数据
cd ~
tar -czf aicode-export.tar.gz .aicode/

# 传输到新机器
scp aicode-export.tar.gz user@new-machine:~/

# 新机器：解压
cd ~
tar -xzf aicode-export.tar.gz

# 新机器：重新安装钩子（因为路径可能不同）
aicode init
```

## 团队共享配置（可选）

在项目仓库根目录创建 `.aicode.json`：

```json
{
  "modules": [
    { "path": "src/frontend/**", "name": "frontend" },
    { "path": "src/backend/**", "name": "backend" },
    { "path": "src/shared/**", "name": "shared" }
  ],
  "ignore": [
    "tests/fixtures/**",
    "**/*.generated.ts"
  ]
}
```

```bash
# 提交到版本控制
git add .aicode.json
git commit -m "chore: 添加 aicode 模块映射配置"
```

团队成员 clone 后，这些配置自动生效（但 reporter 仍需各自配置）。
